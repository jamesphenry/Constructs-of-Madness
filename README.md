## 📚 About This Repository

**Constructs-of-Madness** is a mad scientist template system for building polyglot .NET experiments, frameworks, and scientific artifacts.

This repository serves as a living laboratory for:
- Experimental software patterns
- Polyglot Notebook-driven exploration
- Framework testing beyond reason
- Organized scientific chaos

## 🧪 Scripts

- `new-mad-experiment.ps1` — Creates a new experiment and directory.
- `refresh-experiments.ps1` — Refreshes `docs/experiments.md`.
- `fix-badges.ps1` — Fixes README.md badge links based on the repo URL.

---

## 🚀 Quick Start

```bash
git clone https://github.com/yourname/constructs-of-madness.git
cd constructs-of-madness
cp scripts/.env.template scripts/.env
# Fill in your .env variables

# Start your first experiment!
./scripts/new-mad-experiment.ps1
```
